Harmonic Lab 🎧

Aplicação web desenvolvida para explorar a compatibilidade harmônica entre faixas musicais usando os conceitos do Camelot Wheel.

Sobre o projeto:

O Harmonic Lab nasceu da conexão entre música, produção musical e desenvolvimento web. A aplicação permite visualizar faixas, consultar características musicais e explorar combinações de tonalidades para auxiliar no planejamento de sets de DJ.

Funcionalidades:

Biblioteca de faixas musicais com informações de gênero, BPM, tonalidade e energia.

Consulta de compatibilidade harmônica baseada em regras da roda Camelot.

Formulário de perfil do DJ com validação dos campos.

Envio de dados por GET e apresentação dos parâmetros na página de resultado.

Página com informações sobre o conceito e o desenvolvimento do projeto.

Tecnologias utilizadas:

HTML5: estruturação das páginas e formulários.

CSS3: estilos, identidade visual e organização da interface.

JavaScript: lógica de compatibilidade, validação, manipulação do DOM e processamento dos parâmetros da URL.

Como executar:

Baixe ou clone este repositório.

Abra o arquivo index.html em um navegador.

Navegue pela biblioteca, teste a compatibilidade e experimente o formulário.

O projeto utiliza tecnologias web nativas e não requer frameworks para sua execução.

Limitações atuais:

A compatibilidade é calculada a partir das tonalidades cadastradas e de regras simplificadas da roda Camelot. A aplicação ainda não analisa arquivos de áudio nem importa automaticamente bibliotecas musicais.

Possíveis evoluções:

Cadastro de novas faixas.

Integração com bibliotecas musicais.

Análise automática de tonalidade e BPM.

Recomendações musicais mais avançadas.
